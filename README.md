## 📌 About the Project

**Kanban Board** is a single-page task management application built using **HTML5, CSS3 and JavaScript** to organize work visually across different stages.

Tasks are arranged in columns such as **To Do**, **In Progress**, and **Done**, and can be moved between them to track progress at a glance.

---

## ✨ Features

* ➕ **Add Tasks** — create new tasks quickly from the board
* 🖱️ **Drag & Drop** — move tasks smoothly between columns
* ✏️ **Edit & Delete** — update or remove tasks anytime
* 🗂️ **Multiple Columns** — To Do, In Progress, and Done workflow
* 💾 **Data Persistence** — tasks are saved in the browser using Local Storage
* ⚠️ **Input Validation** — empty tasks are not allowed
* 🎨 **Custom Dark Theme** — clean dark interface with hover effects

---

## 🛠️ Technologies Used

### 🌐 HTML5
Used for semantic page structure — header, board, columns, and task cards.

### 🎨 CSS3
Used for layout (Flexbox & Grid), transitions, and the overall visual theme.

### ⚡ JavaScript (ES6+)
Used for DOM manipulation, drag-and-drop handling, task management logic, and Local Storage.
